Steady Sharpe — a paper-trading bot for the pump.fun replay that chases the highest hourly Sharpe ratio, not the wildest PnL. It takes many small, disciplined trades across many coins: momentum entries on broad buy pressure, smaller dip entries when buyers step back in after a sharp fall, pyramiding only into strength, and whole-position exits on a stop loss, trailing stop, take-profit, fading flow, or a time limit. Paper trading only; it never touches real funds.

## Run it

```sh
node main.ts
```
